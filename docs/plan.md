   修法:用 `sessionStorage` 标记"这个标签页还活着"——**刷新时它保留,关掉标签页后清空**。现在:
   - **F5 刷新** → 认作刷新,接着玩(整屏内容原样接上);
   - **×关闭后再打开** → 认作重新打开,停在封面;点「加载存档」才会看到「▽ 以前的信息」。
   兜底:万一浏览器禁用了 sessionStorage,退回"总是续玩"的旧行为。
2. **汉字字体换成黑体**:CSS 字体栈由 `Consolas, "NSimSun", "新宋体", monospace`
   改为 `Consolas, "SimHei", "黑体", monospace`(ASCII 仍用 Consolas,中文用黑体)。
