## 界面结构(当前)

- 封面 `#cover`:游戏标题 + [ 新游戏 ] + [ 加载存档 ] + 版本号。无存档时「加载存档」禁用。
- 游戏 `#screen`:启动序列 → 顶栏(标题 / 计时)+ 日志流 + 侧栏读数 + 命令行(输入行 + save/exit 按钮)。
- 命令面板 `#palette`:紧贴输入行下方;前缀匹配、字母序、Tab 补全到第一项;最多 3 行、超出可滚动。
- 设置 `#settings`:音乐 / 音效音量滑杆。[ 退出 ] 进 `#quit`(会话已终止兜底画面)。
- 存档:localStorage,键名 `vn-01-save`,存 { v, savedAt, active, material, probes, timeSec, importantLog }。
  运行中每 3 秒自动存一次;`active` 决定刷新后是**自动续玩**还是停在封面。
- 时间只在游戏运行时流动;停在封面时不计时。

## 已锁定的设计决策

- **题材**:自复制太空探测器。机制 = 设定:指数增长本身就是「自我复制」。
- **界面**:仿命令行终端,而且是 **diegetic** 的——界面就是探测器自己的控制台,
  不是「套了层皮的菜单」。呈现 = 设定。
- **叙事**:以终端日志形式展开。叙述者是一台没有感情的机器,所以日志天然是**冷的**;
  「人味」来自它与人类旧信息(来自地球的旧日志/信件)的**对比**,不靠煽情旁白。
  好处:不必写「有感情的散文」,只需写「冷日志 + 少量人类碎片」。
- **交互**:命令栏走「A + B」——既能点、也能敲。点击功能后续由**科技树**解锁,
  现阶段只能输入命令(见 `docs/research.md` 第 1 节)。
- **差异化**:题材和终端风格都有前人(见 README 相关作品清单),不靠它们取胜。
  真正的护城河在**声音/语气**,以及那个「别人替代不了的细节」。

## 手动回归清单(每次改完跑一遍)

1. 打开 `index.html`,控制台(F12)无红色报错
2. 输入 `mine` 回车:材料 +1;连续多次只显示一行 `× N`
3. 材料够 10 时输入 `replicate` 回车:材料 -10、探测器 +1、产出变大
4. 输入 `save` 回车:出现「进度已保存」
5. 输入 `exit` 回车:回封面且已自动保存;再「加载存档」:先出现「▽ 以前的信息」
6. 刷新页面:存档、设置都还在
