## 已锁定的设计决策

- **题材**:自复制太空探测器。机制 = 设定:指数增长本身就是「自我复制」。
- **界面**:仿命令行终端,而且是 **diegetic** 的——界面就是探测器自己的控制台,
  不是「套了层皮的菜单」。呈现 = 设定。
- **叙事**:以终端日志形式展开。叙述者是一台没有感情的机器,所以日志天然是**冷的**;
  「人味」来自它与人类旧信息(来自地球的旧日志/信件)的**对比**,不靠煽情旁白。
  好处:不必写「有感情的散文」,只需写「冷日志 + 少量人类碎片」。
- **交互**:命令栏走「A + B」——既能点、也能敲。点击功能后续由**科技树**解锁,
  现阶段只能输入命令(见 `docs/research.md` 第 1 节)。
- **差异化**:题材和终端风格都有前人(见 README 相关作品清单),不靠它们取胜。
  真正的护城河在**声音/语气**,以及那个「别人替代不了的细节」。

## V0.1.1 研究结论(摘要,详见 `docs/research.md` 第 10–15 节)

- **4 资源闭环**:材料(硬件资本)→ 反应堆 → 能量(运行许可)→ 计算核心 → 算力(槽位预算)
  → 解析器 → 数据(研究货币)→ 科技。整数配比 **3 反应堆 : 4 核心**。
- **倍增定律**:成本 ×r、效果 ×m 时,一次 ×m 顶 `ln m / ln r` 次购买(r=1.10 → ×2 顶 7.3 次)。
  所以科技效果必须写成乘算倍率。
- **选定数值**:探测器成本增长 1.10、解析 0.2 数据/秒/槽 → 12 项科技 **12.9 分钟**走完,
  15 分钟时 50 台探测器(与现有剧情节点对齐,**不动剧情文本**)。
