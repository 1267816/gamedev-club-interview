## 附录 A. 引导提示（输入框为空时常显的那一行，取满足条件的最后一条）
- （执行过 0 条命令后）可输入： /mine 采集材料（直接输入 / 可查看全部命令）
- （材料 ≥ 10）可输入： /replicate 消耗材料，复制一个探测器
- （探测器 ≥ 2）继续积累材料，复制自身。探测器越多，材料产出越快
- （探测器 ≥ 10）扩张中。目标：更多的探测器、更远的坐标
- （解锁「reactor」后）去科技树建造「反应堆」，计算核心需要电力
- （解锁「core」后）建造「计算核心」拿到算力槽，再决定搭载的模块
- （解锁「decode」后）装上「解析器」开始积累数据，可以消耗数据解锁科技
- （探测 ≥ 5%）探测进度靠探测器数量提速，扫描范围要靠「长距离通信」扩展
- （正在研究时）研究进行中。可以继续 /mine、建造或复制，时间到自动完成
- （装过「rep」）复制助手在自动花钱复制。不想要就输入 /rep off 停用（/rep on 重新启用）
