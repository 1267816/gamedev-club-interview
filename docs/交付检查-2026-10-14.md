
## 2. 交付前固定动作

```
node tools/check-parity.js          # 数值一致性（73 项）
node tools/checks/run-all.js        # 全部 jsdom 自测（11 套，约 2 分钟，并行）
node tools/checks/chrome-01-layout.js   # 无头 Chrome 三套（可选，需要本机装 Chrome）
node tools/checks/chrome-02-midgame.js
node tools/checks/chrome-03-tech-ending.js
```

`tools/checks/node_modules` 不入库：换机器第一次跑要先在该目录 `npm i jsdom`。

## 3. 面试官视角的 5 分钟验收路径

1. 双击 `index.html`（Chrome / Edge）→ 封面：标题 + 五个按钮 + 版本号
2. [ 新游戏 ] → 音量提示（耳机图标）→ [ 进入 ] → 启动序列（满屏问号 → 一次性还原）
3. 输入 `/mine` 攒材料 → `/replicate` 复制 → 第一段人类残片（暖色、慢打字）出现
4. `/research` 打开科技树：立项 → 研究 12 秒 → 完成才解锁（研究期间可以继续采矿）
5. 玩到探测 75%：回声塔连接 → `/stay`（园丁）或 `/go`（星海漫游，需先研究「星际航行」）
6. 结算画面 → [ 回到选择时刻 ] 可以回档收齐两个结局

## 4. 已知取舍（都写在 README 的"已知取舍"里）

- WAV 循环在 `file://` 下可能有一帧接缝（要 WebAudio + 本地服务器才能彻底解决）
- 少数禁用本地存储的浏览器不落盘（已做降级，不会崩）
- 没有离线收益（切后台最多按 5 秒结算）
- 65 秒以后的中后期数据没有新出口（界面会写明"已无待研究项目"）
